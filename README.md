# home-soc-security-lab
Home SOC & Security Monitoring Lab

Project Overview

This project documents the development of a personal Security Operations Center (SOC) homelab designed to explore security monitoring, network defense, vulnerability detection, and centralized log management.

The environment combines Proxmox virtualization, Ubuntu Server, Wazuh SIEM, and OPNsense firewall infrastructure to create a hands-on cybersecurity monitoring environment.

Objectives

Deploy and configure a centralized Wazuh SIEM server.

Integrate firewall security logs from OPNsense.

Monitor endpoints and analyze security events.

Explore vulnerability detection and security monitoring.

Develop practical SOC analysis and incident investigation skills.
